## 🚀 Getting Started

### 📋 Prerequisites

* 🟢 Node.js (v14 or higher)
* 📦 npm or yarn

### 📥 Installation

```bash
npm install
```

### ▶️ Run Development Server

```bash
npm start
```

Open:

```text
http://localhost:3000
```

### 🏗️ Build for Production

```bash
npm run build
```

Production files will be generated inside:

```text
build/
```

## 🗂️ Project Structure

```text
src/
├── components/
├── portfolio.js
├── App.js
public/
└── index.html
```

### 📁 Main Editable Files

* 📝 `src/portfolio.js` → Portfolio content
* 🧩 `src/components/` → UI sections
* 🏠 `src/App.js` → Main application component
